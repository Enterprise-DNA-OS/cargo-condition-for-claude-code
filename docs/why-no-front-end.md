# Why there is no front end

The receiving manager's work is reviewing condition history, seal differences, missing photographs and unresolved issues. Those are questions about records. The CLI answers them and produces branded condition reports and handover records.

The free version imports form results or records inspections through the coding agent. Attach photographs already saved on disk. `npm run view` produces read-only HTML; there is no application server.

Cargosnap's phone capture, offline forms, barcode scanning, customer portal and live synchronisation are useful features that this free base does not provide. A screen also makes repeated warehouse-floor data entry easier. Teams needing that capture workflow keep it until their customised version has been built and tested. Enterprise DNA can build those screens and connections around this database.

Hashes detect changed evidence after it is stored. They do not authenticate a photographer. Release checks organise the review; trained staff still inspect and decide.
